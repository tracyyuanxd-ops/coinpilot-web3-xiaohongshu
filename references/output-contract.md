# Output contract

## Complete daily or specific-topic draft

Return sections in this order:

1. **今日选题及推荐理由** — State the reader problem and why the topic is useful now.
2. **标题备选** — Give three clearly different Xiaohongshu titles, not minor variants.
3. **封面文案** — One concise line that works independently.
4. **开场钩子** — 100–180 Chinese characters; use an opening pattern different from the two most recent posts.
5. **完整正文** — Clear, editable copy with concrete mechanisms and restrained subheads.
6. **轮播图脚本** — 6–8 pages. For each page provide `页码 / 页面文案 / 画面建议`.
7. **结尾互动问题** — Ask one specific question that is easy to answer.
8. **话题标签** — Provide 8–12 relevant tags; avoid irrelevant traffic tags.
9. **事实核查与风险提示** — List verified claims, uncertain items, and the required risk statement.
10. **参考来源** — Source name, direct link, and publication or update date.

## Two-week plan or idea pool

For each topic include:

- Sequence number or proposed date
- Topic and beginner question
- Learning objective
- Key angle and what makes it distinct
- Prerequisite topic, if any
- Suggested opening form
- Status: idea / researching / drafting / reviewed / published

Order the plan from foundations to actions, safety, applications, and deeper mechanisms. Treat previously published topics as prerequisites rather than repeating them.

## Short-form exceptions

If the user explicitly asks only for titles, an outline, carousel pages, a rewrite, or a visual brief, return that requested subset. Preserve research, integrity, voice, and risk standards even when shortening the deliverable.
