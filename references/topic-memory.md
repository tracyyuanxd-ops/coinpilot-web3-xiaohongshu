## Status model

- **Published:** The user explicitly says the post was published or provides equivalent evidence. Treat it as a strong deduplication constraint. Revisit only for a material, verified update or a clearly different reader question.
- **Drafted:** A complete or substantial draft exists, but publication is not confirmed. Avoid repeating it in the immediate content cycle; it may be revised, completed, or reused when the user asks.
- **Notified:** Only a topic suggestion, heartbeat alert, headline, or short concept was returned. Do not treat it as completed content. It remains eligible for a future full draft, while avoiding duplicate notifications on the same day.

Only the user, or direct publication evidence supplied by the user, can promote an item to **Published**. When evidence is unclear, use **Drafted** for substantial copy and **Notified** for a topic-level alert.
